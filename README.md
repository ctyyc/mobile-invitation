# Mobile Wedding Invitation

HTML, CSS, JavaScript만으로 만든 반응형 모바일 청첩장입니다.

## 정보 변경

- `index.html`: 이름, 인사말, 연락처, 계좌번호, 사진, 예식장 정보
- `script.js`의 `CONFIG`: 예식 일시, 제목, 장소, 주소
- `styles.css`의 `:root`: 색상과 글꼴

## 주요 기능

- 모바일 우선 반응형 레이아웃
- 예식일 달력과 D-day
- 3열 × 3행의 둥근 정사각형 썸네일 9장과 클릭 시 전체 사진 18장 보기
- 사진 보기 화면은 크기를 고정하고 터치 확대 제스처를 제한합니다.
- 지도 앱 연결
- 계좌번호 복사
- 캘린더 일정 파일 저장
- Web Share API 및 주소 복사
- 배경음악 재생 버튼(우측 상단): 첫 터치 때 재생을 시도하고, 버튼으로 켜고 끌 수 있습니다.
- 스크롤 등장 애니메이션과 접근성 대응

## 사진 구성

- `image/001.jpeg` 등 웨딩 사진 18장: 긴 변 최대 1,920px, JPEG 품질 82의 확대용 이미지
- `image/preview/`: 긴 변 최대 1,200px인 표지·갤러리 썸네일·마무리 화면용 이미지 11장
- 사진 비율과 색상 프로필은 유지한 채 리사이즈했습니다.
- 갤러리 버튼의 `data-full`은 확대용 이미지 경로입니다. `script.js`의 `CONFIG.allPhotos`에도 해당 경로를 등록합니다.
- 고해상도 원본은 `marry/` 디렉터리에 보관되어 있습니다. 사진을 다시 가공할 때는 원본을 사용해 주세요.
- `image/map-inner.jpg` 약도는 기존 파일을 유지합니다.

## 배경음악

- `audio/bgm.mp3`: 잔잔한 피아노풍 곡(약 53초, 반복 재생, 0.7MB). 외부 음원 없이 직접 합성한 오리지널 곡이라 저작권 문제가 없습니다.
- 모바일 브라우저는 소리 자동 재생을 막으므로 첫 터치 때 재생을 시도합니다. 기본 볼륨은 `script.js`의 `bgm.volume`(0.4)입니다.
- 다른 곡으로 바꾸려면 같은 이름(`audio/bgm.mp3`)으로 교체하면 됩니다. 이용 허락을 받은 곡이나 로열티프리 음원인지 라이선스를 먼저 확인해 주세요.

## 디자인

화이트 바탕, 명조체, 아치형 웨딩 사진 컨셉을 유지합니다. 표지는 이름·사진·일시를 순서대로 배치하고, 갤러리와 안내 영역에는 공통 여백과 서체 크기를 적용합니다. 버튼은 최소 48px 높이로 구성하며 사진 보기 화면에서는 조작 버튼이 사진과 겹치지 않도록 공간을 분리합니다.
