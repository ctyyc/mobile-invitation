# Mobile Wedding Invitation

HTML, CSS, JavaScript만으로 만든 반응형 모바일 청첩장입니다.

## 정보 변경

- `index.html`: 이름, 인사말, 연락처, 계좌번호, 사진, 예식장 정보
- `script.js`의 `CONFIG`: 예식 일시, 제목, 장소, 주소
- `styles.css`의 `:root`: 색상과 글꼴

## 주요 기능

- 모바일 우선 반응형 레이아웃
- 예식일 달력과 D-day
- 갤러리와 전체 화면 사진 보기
- 지도 앱 연결
- 계좌번호 복사
- 캘린더 일정 파일 저장
- Web Share API 및 주소 복사
- 스크롤 등장 애니메이션과 접근성 대응
