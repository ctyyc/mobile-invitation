# Mobile Wedding Invitation

HTML, CSS, JavaScript만으로 만든 반응형 모바일 청첩장입니다.

## 정보 변경

- `index.html`: 이름, 인사말, 연락처, 계좌번호, 사진, 예식장 정보
- `script.js`의 `CONFIG`: 예식 일시, 제목, 장소, 주소
- `styles.css`의 `:root`: 색상과 글꼴

## 주요 기능

- 모바일 우선 반응형 레이아웃
- 예식일 달력과 D-day
- 사진 6장을 표시하는 정적 갤러리 (클릭 확대 없음)
- 지도 앱 연결
- 계좌번호 복사
- 캘린더 일정 파일 저장
- Web Share API 및 주소 복사
- 스크롤 등장 애니메이션과 접근성 대응

## 사진 구성

- `image/001.jpg` 등 웨딩 사진 21장: 긴 변 최대 1,920px, JPEG 품질 85의 보관용 이미지 (현재 화면에서 사용하지 않음)
- `image/preview/`: 긴 변 최대 1,200px인 표지·갤러리 썸네일·마무리 화면용 이미지 8장
- 사진 비율과 색상 프로필은 유지하며, EXIF 방향을 적용한 뒤 EXIF·XMP 메타데이터를 제거했습니다.
- 갤러리 사진은 `index.html`의 `.gallery__item`에서 변경합니다. 확대 화면과 사진 넘김 기능은 제공하지 않습니다.
- 고해상도 원본은 리사이즈 이전 Git 커밋에서 복원할 수 있습니다. 사진을 다시 가공할 때는 원본을 사용해 주세요.
- `image/map-inner.jpg` 약도는 기존 파일을 유지합니다.
